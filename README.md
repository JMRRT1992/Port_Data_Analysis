# Portafolio de proyectos de análisis de datos y ciencia de datos:
En este repositorio estaré almacenando algunos de los trabajos más relevantes que realice como analista de datos. En general, todos los trabajos que estaré cargando serán aquellos que realice en los cursos, capacitaciones, certificaciones y demás actividades académicas en las que participe puesto que, por cuestiones de confidencialidad, no podré subir casos reales de los clientes con los que he trabajado o trabajaré.


# Objetivo
Este repositorio se creó para poder almacenar los trabajos de análisis de datos que puedan ser compartidos más adelante.

Así mismo, con este espacio busco tener a la mano y de forma accesible los principales trabajos que he realizado como estudiante, de modo que posteriormente tenga un rápido acceso a ellos para consulta. Por otro lado, el almacenar los proyectos en un único repositorio me dará el beneficio de saber donde se almacenan este tipo de documentos en un futuro y no tener múltiples ubicaciones para cada trabajo.
